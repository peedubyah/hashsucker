# Wiki rule (read once)

**Repo docs are canonical. This wiki is a one-way human-readable
projection.** Summarize and link back; never copy authority here.

- Canonical sources: `AGENTS.md`, `GOALS.md`, `PLANS.md`,
  `docs/architecture.md`, `docs/BUILD-LOG.md`, `docs/ROADMAP.md`,
  `src/PRODUCTION-PLAYBACK-TESTING.md`, `handoff/CURRENT.md`
  (live facts only).
- Wiki edits must never change architecture, plans, sequencing, or
  acceptance mechanics. If a wiki page and a repo doc disagree, the repo
  doc wins — fix the wiki, never the reverse.
- No bidirectional sync. Regenerate or hand-update pages from canonical
  sources as needed.
