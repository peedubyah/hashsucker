# HashSucker v0.2.0 — hardened production state

34 commits past v0.1.0. Same product, proven end to end: fresh pull
from GHCR becomes playable with empty state, survives power-cycles,
and upgrades atomically. Install and update per `UNRAID.md`.

## What improved

- **Playback reliability.** Same-TorrentFile provider recovery across
  restarts, dead-peer watchdog with reactive same-file failover,
  cancellation/backfill hardening, and reduced duplicate provider work
  (skip pre-acquire/prefix-backfill when already covered).
- **Fresh corpus bootstrap + incremental lifecycle.** Bounded background
  sessions converge a blank install to usable in about an hour while
  live sources carry requests from minute one; revision-pinned deltas
  advance only on verified-complete coverage.
- **Invalid-fragment quarantine.** Permanently-invalid upstream artifacts
  (13 observed: 404 pages, empty shells served as HTTP 200) quarantine
  per-tree after 5 consecutive deterministic failures instead of vetoing
  the revision claim forever. Transient failures never quarantine.
- **Anticipatory Arr sourcing.** Sonarr/Radarr sensors import monitored
  upcoming items as future intents; the scheduler prepares through the
  existing pipeline (quality floor, prepare-then-publish windows) so
  explicit requests resolve from prepared truth in milliseconds.
- **Cold-boot / self-heal appliance behavior.** Total service stop to
  playable in under 20 seconds with exact bytes; adversarial ordering
  (any start order, backend restarts under mount, rclone kill) and
  mid-stream Rust/Node restarts all recover without intervention.
- **Deployment, permission, readiness, config fixes.** First-boot
  ownership repair for both containers, queue dirs ensured (readiness
  honest from boot), shared-queue group mediation, canonical path
  precedence over legacy aliases, TorBox URL override honored by the
  readiness probe, atomic update + rollback procedure documented.
- **GHCR conveyor proven.** CI builds all four services per main push
  (`:main` + `:sha-*`); releases are immutable version + semver
  aliases + `:latest` with OCI revision labels. Digest-pinned fresh
  deploy and older→newer upgrade both proven with exact bytes.

## Upgrade

`docker compose pull && docker compose up -d` (atomic, all services).
No manual migration. Rollback is schema-safe; see `UNRAID.md`.
