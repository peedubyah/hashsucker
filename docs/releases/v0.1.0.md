# HashSucker v0.1.0 — first packaged release

Prebuilt images, two-path config, background corpus that stays out of the
way. Install: `.env` → `docker compose pull` → `docker compose up -d`.

## What it does

- **Request → discovery → ranked release.** Corpus (DMM hashlists) +
  live fanout (Torrentio, Comet, Torznab, Prowlarr) merged on exact
  release identity, scored on evidence with hard identity gates.
- **Provider execution.** TorBox fully; Real-Debrid for discovery,
  binding data, and serving where configured. Availability is re-checked
  at request and playback time, not just discovery time.
- **Durable identity + VFS/STRM publication.** Stable per-title URLs that
  survive provider eviction, mount moves, and expired CDN links
  (redirect decision instead of broken library entry).
- **Prepared fulfillment.** Discovery/binding ahead of demand; human
  requests complete in milliseconds off prepared truth.
- **Anticipatory publication.** Future intents (operator, Arr, Seerr)
  prepare inside movie (~30d) / TV (~3d) windows and publish inside
  narrower ones — speculative CAM/TS/TC never presented (quality floor).
- **Deferred Seerr demand.** Unavailable requests become durable intent
  (202 deferred, exact S/E) instead of dying; `MEDIA_AVAILABLE`
  webhooks wake them in seconds.
- **Sonarr/Radarr sensors.** Monitored movies/episodes become intent;
  files-present parks, unmonitored withdraws (prepared truth survives).
- **Prowlarr candidate sourcing** with key-safe handling.
- **Resumable background corpus bootstrap.** Bounded sessions (~1000
  fragments), per-fragment checkpoints, `usable-partial` serving state,
  crash/resume safe.

## Limitations (honest)

- TorBox is REQUIRED CORE today; **Real-Debrid-only deployment is not
  supported** (data-plane + provider construction require TorBox).
- **arm64 images publish but are unverified** (no arm hardware in CI scope).
- No management UI by design (diagnostics JSON + startup summary only).
- First corpus baseline downloads ~1.6 GB once and takes about an hour
  of polite background work; requests work from minute one.
