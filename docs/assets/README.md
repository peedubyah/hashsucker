# HashSucker brand assets

- `logo.png` — **master artwork, do not modify.** Comic-book shop vacuum, red/charcoal/cream, hash fragments. 1254×1254 RGBA.
- `icon-512.png` / `icon-256.png` / `icon-128.png` / `icon-64.png` — deterministic LANCZOS downsamples of the master for UI contexts. No JPEG, transparency preserved.
- No banner: the square logo plus the README header carries the opening; no fabricated typography art.

Intended use:

- `icon-256.png` — GitHub social/README header (current), Unraid Community Apps icon URL, Docker Hub overview.
- `icon-512.png` — high-density displays, app-store style listings.
- `icon-64.png` — favicons, tab icons, small badges.
